Project 04 · Data visualisation

Global Map of EV Charging Stations

A data visualisation showing an interactive map with route planning for electric vehicles and 10,000 charging points spread across the world.

HTML5 JavaScript Data Viz GeoJson Leaflet.js

Context

The problem

Several visualisations already show the charging points available for electric cars, but their data usually comes only from energy operators and, in many cases, is submitted directly by users. Many of them are also limited to certain territories, so they show no charging points in other countries or regions. Finally, they rarely allow filtering by categories such as plug type: they simply show a map with the charging points and the characteristics of each one.

The goals

The aim of the project is to create a visualisation where the user can interact with a world map and which overcomes many of the drawbacks found in existing visualisations. The map shows the charging points with detailed information about each one and adds several features that extend the possibilities of the underlying dataset.

The audience

The project is aimed at current and future electric vehicle drivers who need to plan routes around charging point availability. It is also useful for logistics companies managing electric fleets, urban planners interested in sustainable mobility infrastructure, and anyone who wants to explore the current state of the global charging network.

Approach

Research

The process began by analysing several existing visualisation platforms and identifying their limitations in geographic coverage and filtering. I evaluated tools such as Flourish, which proved insufficient because they do not allow precise geolocation of individual points. I studied the dataset of 10,000 charging stations, working through its 14-column structure with detailed information on each point. Finally, I identified the need to convert the original CSV format to GeoJSON to make it compatible with interactive JavaScript mapping libraries.

Design decisions

I chose to build the visualisation in plain HTML and JavaScript, using my programming skills to keep full creative freedom. I implemented Leaflet.js with OpenStreetMap as the base map, giving a detailed world map that works across devices. I designed a country filter using a dropdown selector so users can focus on specific territories. I created an information panel in the top left corner showing live statistics. I also developed an interactive route builder that calculates distances between selected charging points, adding practical value beyond the original dataset.

Technical challenges

The biggest challenge was computing accurate distances between charging points, which required the Haversine formula to account for the curvature of the Earth. Converting the dataset from CSV to GeoJSON while making sure the geospatial coordinates were interpreted correctly was another significant hurdle. Handling 10,000 data points on the map called for performance optimisation to keep the interaction fluid. Finally, writing multiple custom JavaScript functions (initMap, loadStations, calculateDistance, updateRoute and others) demanded extensive research and testing to guarantee they worked correctly.

Tech stack

01

HTML5

The structure of the visualisation, with CSS3 creating a responsive layout that adapts to different devices.

02

JavaScript

The engine behind every interaction: it loads the GeoJSON dataset, handles events, calculates distances with mathematical algorithms and coordinates all the map's features.

03

Leaflet.js

An open source library for interactive maps. It allows precise geolocation of individual points using OpenStreetMap while keeping performance optimal with 10,000 records.

04

GeoJson

A JSON-based format designed for geospatial data. It stores coordinates (latitude, longitude) that Leaflet.js can process and render precisely on the map.
