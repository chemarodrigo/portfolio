Project 03 · Frontend development

Rick & Morty Character Dashboard

A personal experiment with Vue.js, Nuxt and Pinia: an interactive dashboard that consumes the public Rick and Morty API to explore, filter and save characters from the show's universe

Vue.js Nuxt Pinia Tailwind CSS API

Context

The problem

My frontend development knowledge was centred on vanilla JavaScript, HTML and CSS. That foundation let me build working projects such as data visualisations and web applications, but I wanted to move to modern frameworks like Vue.js to understand how a real frontend application is structured: state management, reactive components, routing, authentication middleware and REST API consumption. The best way to learn a technology is to build something with it.

The goals

Build a complete web application with Vue.js, Nuxt and Pinia including the real features of a digital product: user authentication, navigation between views, consumption of an external API, filtering and search, favourites management and responsive design. All of it deployed to production so it can be shared and shown working in a real environment.

The audience

The project is intended as a portfolio piece and a learning exercise. It is a working demonstration of technical ability with modern frameworks, aimed at showing that I can work with the tools used by today's frontend development teams.

Approach

Research

Before writing a single line of code, I spent time studying the official Vue.js, Nuxt and Pinia documentation to understand each tool's philosophy and how they fit together. I analysed the public Rick and Morty API to understand its endpoints, the structure of paginated responses and the available filtering options (by name, status, species and gender). I also researched common patterns in dashboards and data-query applications in order to define a clear, functional interface.

Design decisions

The interface was designed with a dark aesthetic that suits the show's theme, using Tailwind CSS to keep development fast and consistent. A card system displays each character with their image, name, status (alive, dead, unknown) and last known location. Navigation was split into two main views: the general character catalogue with search and filters, and a favourites section where users can save their preferred characters. A simulated authentication system was added to practise protected routes and middleware in Nuxt.

Technical challenges

The main challenge was learning and applying three new technologies at once (Vue.js, Nuxt and Pinia) with no prior experience of any of them. Managing the application's global state with Pinia, particularly keeping the favourites list in sync across views, required a deep understanding of the reactive store pattern. Implementing infinite pagination of the character catalogue while consuming the API efficiently, without overloading requests, was another significant challenge. Setting up authentication middleware to protect routes and deploying to Vercel completed the end-to-end learning of a professional frontend workflow.

Tech stack

01

Vue.js / Nuxt

A progressive JavaScript framework for building user interfaces, extended with Nuxt to handle routing, rendering and project structure in an organised, scalable way.

02

Pinia

The official Vue.js state manager, used to centralise the application's data: characters loaded from the API, active filters, the favourites list and the user's authentication state.

03

Tailwind CSS

A CSS utility framework that made it quick to build a responsive, visually consistent interface with a dark aesthetic suited to the show's theme.

04

Rick and Morty API

A free, public REST API with data on more than 800 characters. It is consumed to fetch paginated information, apply filters by name, status and species, and display each character's details.
